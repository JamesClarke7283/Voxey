# Jukebox music attribution

These eight Ogg Vorbis files are copied **unchanged** from Mineclonia's
`mods/ITEMS/mcl_jukebox/sounds/`. Voxey has not remixed or edited the recordings.
The source mod's `README.md` identifies the following individual music licenses.
Its Lua code is GPLv3; no source textures were copied into Voxey.

No endorsement by any musician is implied. The game displays track title,
creator and license when playback begins. Full credit text and source/license
URLs are also embedded in `Jukeboxes.CREDITS` for inclusion in exported credits.
